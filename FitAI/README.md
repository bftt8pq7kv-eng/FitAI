# FitAI 👗🤖

FitAI, yapay zekâ destekli akıllı kombin öneri uygulamasıdır.

Kullanıcının:

- bulunduğu şehir
- hava durumu
- tarzı
- etkinliği
- renk tercihi

bilgilerini analiz ederek uygun kombin önerileri üretir.

---

# 🚀 Özellikler

- Yapay zekâ destekli kombin önerisi
- Gerçek hava durumu entegrasyonu
- Modern responsive arayüz
- ASP.NET Core backend
- OpenAI API entegrasyonu
- Dinamik kullanıcı girdileri
- Modern UI/UX tasarımı

---

# 🛠️ Kullanılan Teknolojiler

- ASP.NET Core Web API
- HTML
- CSS
- JavaScript
- OpenAI API
- OpenWeather API
