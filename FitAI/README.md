# FitAI 👗🤖

FitAI, kullanıcının şehir bilgisi, hava durumu, tarzı, etkinlik türü ve renk tercihine göre yapay zekâ destekli kombin önerileri sunan modern bir web uygulamasıdır.

## ✨ Özellikler

- Yapay zekâ destekli kombin önerisi
- Hava durumuna göre kıyafet analizi
- Tarz, cinsiyet, etkinlik ve renk tercihi desteği
- Modern ve responsive web arayüzü
- ASP.NET Core Web API backend
- OpenAI API entegrasyonu
- OpenWeather API entegrasyonu

## 🛠 Kullanılan Teknolojiler

- ASP.NET Core Web API
- C#
- HTML
- CSS
- JavaScript
- OpenAI API
- OpenWeather API

## 🚀 Uygulama Nasıl Çalışır?

1. Kullanıcı şehir, cinsiyet, tarz, etkinlik ve renk tercihini girer.
2. Sistem şehir bilgisine göre hava durumunu analiz eder.
3. OpenAI API kullanılarak kişiye özel kombin önerisi oluşturulur.
4. Sonuç modern arayüzde kullanıcıya gösterilir.
