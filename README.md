# FitAI 👗✨

Hava durumuna, stile ve kullanıcı tercihine göre yapay zekâ destekli kombin önerisi yapan ASP.NET Core uygulaması.

## 🚀 Özellikler

- 🌦️ Hava durumuna göre kombin önerisi
- 🤖 OpenAI destekli akıllı stil önerileri
- 👕 Üst giyim, alt giyim, ayakkabı ve aksesuar önerileri
- 🎨 Kullanıcı renk tercihi desteği
- 💼 Casual, spor, şık gibi stil seçenekleri
- 📱 Modern ve responsive arayüz

---

## 🛠️ Kullanılan Teknolojiler

- ASP.NET Core Web API
- HTML / CSS / JavaScript
- OpenAI API
- REST API
- Git & GitHub
